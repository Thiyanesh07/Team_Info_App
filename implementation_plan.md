# Team Management & Productivity Application

Build a production-level Flutter (Mobile + Web) application with Firebase backend for managing a college team of up to 21 members.

## User Review Required

> [!IMPORTANT]
> **Firebase Project**: You will need to create a Firebase project and configure it using `flutterfire configure`. I will scaffold the Flutter code and prepare all Firebase integration points, but you must:
> 1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
> 2. Enable **Email/Password Authentication**
> 3. Enable **Cloud Firestore** (start in test mode, then apply security rules)
> 4. Enable **Firebase Storage** (for chat images)
> 5. Run `flutterfire configure` after project creation to generate `firebase_options.dart`

> [!IMPORTANT]
> **College Domain Restriction**: The plan restricts registration to `@college.edu`. Please confirm your actual college email domain so I can update it.

> [!WARNING]
> **FCM & Cloud Functions**: Notification triggers require Firebase Cloud Functions (Node.js). I will provide the function code, but deployment requires `firebase deploy --only functions` and a Blaze (pay-as-you-go) plan.

1. Run `flutter analyze` to ensure no static analysis errors

1. **Build Verification**: Run `flutter run -d chrome` to launch the web app and verify it compiles and renders

3. **Navigation**: Verify bottom navigation renders all 5 tabs (Home, Projects, Chat, Activity, Profile)
4. **UI Review**: Visual inspection of all screens for modern, clean design
5. **Role-based Access**: After creating test users, verify different roles see appropriate content
